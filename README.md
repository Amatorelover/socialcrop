# SocialCrop · 社交媒体智能裁图

> 上传一张图片，自动拼接 / 拆切为各大主流社交媒体适配的尺寸与比例。
> 原生 Android（Kotlin + Jetpack Compose），**零权限、不联网**，纯本地处理，隐私友好。

| **按比例裁剪** | 把任意图片裁剪到目标平台比例；可拖动高亮取景框自由选择保留区域（框内清晰、框外模糊），支持一键居中复位；比例列表首项为「原比例」，随原图宽高比输出、完全不裁切 |

## 🖼️ 智能边框（避免黑边/白边）

当任意比例的原图要适配到平台目标比例时，传统做法是「裁掉内容」或「补黑边/白边」。
智能边框改为：按目标比例创建画布 → 完整保留原图 → 剩余区域由可控背景填充。

## 🧩 技术点
- **图片处理引擎**：纯 `Bitmap` + `Canvas` 实现，按目标比例计算取景矩形；长图切格由 `ImageProcessor.planGrid(srcW, srcH, cols, rows)` 统一算出整数格宽高与居中裁切矩形，预览、提示与切图共用，1:1 取块无重采样，只丢弃不能整除的零头像素，保证每张严格相邻、拼回无缝。
- **边框渲染器**：`FrameRenderer` 纯函数，支持柔焦背景（降采样 + 三次 box blur 近似高斯 + 降饱和 / 压暗 / 暗角，无需 RenderScript / 第三方库）、主色提取（48×48 确定性 k-means 返回 5 种差异明显的主色）、任意角度线性渐变、圆角裁剪与描边、多层半透明圆角矩形模拟柔和投影，以及电影边框独立布局（原图完整 + 上下遮罩条 + 双行字幕）。
- **水印渲染器**：`WatermarkRenderer` 纯 Canvas。v2.7.0 起按参考相机水印排布：整体**最多两行居中**，第一行 = Logo（内联在文字左侧）+ 手机型号 / 作者名字，第二行 = 镜头参数（或拍摄时间）/ 时间戳。照片参数的两行由 `deviceOn` / `lensOn` 各自独立开关控制；有 Logo 时机型文字只留品牌后缀、不与 Logo 重复（`SM-S9280`→`S9280`、`iPhone 16 Pro`→`16 Pro`），所有品牌首字母统一大写，并用常规体（对齐 `SAMSUNG` 图标 + `S9280`）。开启 Logo 后照片参数与文字水印互斥（`EditorViewModel.normalizeExclusive` 收敛），保证两行不被撑爆。三类各带一组位移偏移，可上下左右微调。首行微软雅黑、次行同族常规体略小，行宽过长时按可用宽度自适应收敛。位置固定**下方居中**（带边框取下留白带正中、电影模式退用上带、无边框贴底居中），按带高自适应缩小；平铺模式仍铺满整图。投影颜色按前景明暗自动反相。EXIF 现算、**彻底不解析 GPS**；仅用户自有内容，绝不强加 App 品牌标。
- **参数持久化**：`FrameSettingsStore` 用 Android 内置 `org.json` + `SharedPreferences` 序列化，字段缺失自动回落默认值，新增参数不会让旧配置崩溃。
- **内置品牌 Logo**：`assets/brand_logos/` 随包附带 **28 个**透明 PNG（16 手机 + 12 相机，源：[worldvectorlogo.com](https://worldvectorlogo.com)，各品牌商标归原权利人所有），每个另附一份去背白模 `<id>_mono.png`；逐个人工核对过品牌原色（三星深蓝、徕卡红、OPPO 绿、realme 黄等）。水印页选中后从 assets 复制主图 + 白模到 `filesDir`，之后的预览 / 导出与相册 Logo 完全共用渲染器。`decodeLogo` 选白/黑单色化时优先读白模上色（避免 GoPro / 联想 / vivo / 蔡司 / 尼康 / 柯达这类带底色的 Logo 被刷成一整块），用户上传图则在运行时按四角同色去底。
- **隐私**：全程不申请网络权限（`INTERNET` 未声明），图片不离开本机；内置 Logo 也在构建期下载，运行时无网络请求。
- **Compose**：Material3 单 Activity 多界面导航，状态由 ViewModel 持有；边框预览在 `Dispatchers.Default` 异步渲染。
- **国际化**：全部可见文案走字符串资源，枚举/预设显示名映射为资源 ID；应用内语言用 `attachBaseContext` + `recreate()`
  实现，不引入 AppCompat 或第三方库，也不增加任何权限。
