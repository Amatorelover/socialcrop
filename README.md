# SocialCrop · 社交媒体智能裁图

> 上传一张图片，自动拼接 / 拆切为各大主流社交媒体适配的尺寸与比例。
> 原生 Android（Kotlin + Jetpack Compose），**零权限、不联网**，纯本地处理，隐私友好。

| **按比例裁剪** | 把任意图片裁剪到目标平台比例；可拖动高亮取景框自由选择保留区域（框内清晰、框外模糊），支持一键居中复位；比例列表首项为「原比例」，随原图宽高比输出、完全不裁切 |

## 🖼️ 智能边框（避免黑边/白边）

当任意比例的原图要适配到平台目标比例时，传统做法是「裁掉内容」或「补黑边/白边」。
智能边框改为：按目标比例创建画布 → 完整保留原图 → 剩余区域由可控背景填充。

| 样式 | 效果 |
| --- | --- |
| **背景模糊（v2.1.6 两层模糊）** | **两层叠加**：底层 = 同一张原图缩略 → 强模糊 → 饱和度混合 → cover 放大铺满（色系天然继承原图，不再人工染色），顶层 = 清晰照片 + 小圆角 + 宽而软的真实投影浮起；最后一层均匀极轻压暗让前景从模糊底里凸显。不做顶部压暗 / 底部光晕 / 方向光 / 暗角等人工光影。前景照片像素完全不动 |
| **取色渐变** | 从原图 k-means 聚类提取 5 种差异明显的主色做渐变，底部自动绘制主色色卡；叠加柔光避免色块死平 |
| **自定义色** | 8 种预设纯色 + 任意 HEX 输入，同样带柔和光感 |
| **电影边框（v1.9.1 复刻）** | 照片 **COVER 铺满画布**（不缩小、不变形），上下叠遮罩条；主题可选纯黑 / 纯白 / 渐隐（半透明渐变），下方条内放中文主行 + 由内置离线词库自动翻译的英文副行（可开关、可手动微调）；无圆角、无投影、无描边 |

### 🎛 模式与参数（v2.2.0 扁平化）

```
编辑页「边框」分区：4 种模式 2×2 磁贴直接铺开（含选中态）
        │ 点任一模式（套用该模式推荐值）
        ▼
   该模式参数页 ──「完成 / 返回」──▶ 回到编辑页
```

- 编辑页「边框」分区直接平铺 4 种模式磁贴：背景模糊 / 取色渐变 / 电影边框 / 自定义色，选中态用主色描边；下方「关闭边框」一行一键关掉。v2.2.0 起删掉二级模式列表页，换模式在编辑页一点即可，不再绕路。
- 每选一种模式就套用该模式的推荐默认值（字幕内容跨模式保留；v2.1.8 起输出固定无损，不再跨模式保留分辨率）；参数页**不提供模式切换**，也不再有「快速预设」区，避免两处都能改模式、参数堆成一团。

## 🧩 技术点
- **图片处理引擎**：纯 `Bitmap` + `Canvas` 实现，按目标比例计算取景矩形；长图切格由 `ImageProcessor.planGrid(srcW, srcH, cols, rows)` 统一算出整数格宽高与居中裁切矩形，预览、提示与切图共用，1:1 取块无重采样，只丢弃不能整除的零头像素，保证每张严格相邻、拼回无缝。
- **边框渲染器**：`FrameRenderer` 纯函数，支持柔焦背景（降采样 + 三次 box blur 近似高斯 + 降饱和 / 压暗 / 暗角，无需 RenderScript / 第三方库）、主色提取（48×48 确定性 k-means 返回 5 种差异明显的主色）、任意角度线性渐变、圆角裁剪与描边、多层半透明圆角矩形模拟柔和投影，以及电影边框独立布局（原图完整 + 上下遮罩条 + 双行字幕）。
- **水印渲染器**：`WatermarkRenderer` 纯 Canvas，文字 / 本地 Logo 任意组合，单点 + 平铺，阴影提升可读性；v2.1.8 起位置固定**下方居中**（带边框取下留白带正中、电影模式退用上带、无边框贴底居中），默认字体微软雅黑无衬线粗体（缺字体回退系统 sans-serif bold）；v1.9.3 起可由 `util/ExifReader` 本地解析 EXIF 自动填充文字（机型 / 镜头 / 光圈 / 快门 / ISO / 焦距 / 时间，GPS 可选但默认关）；仅用户自有内容，绝不强加 App 品牌标。
- **参数持久化**：`FrameSettingsStore` 用 Android 内置 `org.json` + `SharedPreferences` 序列化，字段缺失自动回落默认值，新增参数不会让旧配置崩溃。
- **隐私**：全程不申请网络权限（`INTERNET` 未声明），图片不离开本机。
- **Compose**：Material3 单 Activity 多界面导航，状态由 ViewModel 持有；边框预览在 `Dispatchers.Default` 异步渲染。
- **国际化**：全部可见文案走字符串资源，枚举/预设显示名映射为资源 ID；应用内语言用 `attachBaseContext` + `recreate()`
  实现，不引入 AppCompat 或第三方库，也不增加任何权限。
